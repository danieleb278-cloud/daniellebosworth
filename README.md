# Danielle Portfolio

Create a modern portfolio website for a Product Strategy, UX, and Marketing professional. The brand is "dscript". The aesthetic should be editorial, minimalist, systems-oriented, and typography-driven. Include a hero section, about section, featured projects section, resume section, and contact section. Focus on responsiveness, readability, and hiring managers reviewing case studies. include animations and easy navigation for 3 case studies, use place holder information for featured projects/case studies.
